ABOUT THE PROJECT

About CyberShield

CyberShield is an academic project developed using Python, Flask, HTML, and CSS. It checks selected HTTP security headers, HTTPS usage, HTTP response status, and response time.

The security score is a custom educational indicator and should not be treated as an official security rating.
